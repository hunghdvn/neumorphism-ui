The components are standard Custom Elements: they take part in native forms, render as declarative
shadow DOM so they look right before JavaScript loads, and follow a light or dark theme made of
five CSS variables. Start with [Installation](/neumorphism-ui/getting-started/installation/), read
the [Theming guide](/neumorphism-ui/guides/theming/), or open a component such as the
[button](/neumorphism-ui/components/button/) or the [text field](/neumorphism-ui/components/text-field/).
