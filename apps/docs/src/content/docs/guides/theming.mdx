Everything visual comes from `@neumorphism-ui/tokens/neu.css`. It defines a handful of custom
properties; every shadow, text colour and tint is derived from them. Try them in the
[theme playground](/neumorphism-ui/) on the home page.

## The five variables

| Variable          | Light (default) | Dark (default) | Meaning                                                        |
| ----------------- | --------------- | -------------- | -------------------------------------------------------------- |
| `--neu-bg`        | `#e0e5ec`       | `#2b2f36`      | Background colour. Everything else is computed from it.        |
| `--neu-accent`    | `#6d5dfc`       | `#8b7dff`      | Accent colour, for primary buttons, focus rings and checks.    |
| `--neu-distance`  | `6px`           | `6px`          | Shadow distance of the `md` size.                              |
| `--neu-intensity` | `1`             | `1`            | Shadow strength factor, unitless: `0.5` is softer, `2` harder. |
| `--neu-radius`    | `12px`          | `12px`         | Corner radius of the `md` size.                                |

There are also `--neu-success`, `--neu-warning` and `--neu-danger` (status colours used by badges
and error messages), `--neu-font` and `--neu-duration` (`150ms`, and `0ms` when the user prefers
reduced motion).

Override any of them in your own CSS:

```css
:root {
  --neu-accent: #0f9d76;
  --neu-radius: 20px;
}
```

## Optional overrides

Four more variables are never set by the tokens, so you can set them when the computed value is
not what you want:

| Variable             | Overrides                      |
| -------------------- | ------------------------------ |
| `--neu-shadow-dark`  | The dark half of every shadow  |
| `--neu-shadow-light` | The light half of every shadow |
| `--neu-fg`           | Text colour                    |
| `--neu-fg-muted`     | Secondary text colour          |

Without them the shadows and the text colour are mixed from `--neu-bg`, so changing the
background alone gives a matching shadow and readable text.

## Light and dark

Set `data-neu-theme="light"` or `data-neu-theme="dark"` on any element to choose a theme for that
subtree. Without the attribute the page follows `prefers-color-scheme`.

<Demo
  code={`<div class="neu-surface" data-neu-theme="light">
  <neu-button variant="primary">Light</neu-button>
</div>
<div class="neu-surface" data-neu-theme="dark">
  <neu-button variant="primary">Dark</neu-button>
</div>`}
/>

To give each theme its own value, override with the same selectors the tokens use. A bare `:root`
override applies to both themes:

```css
:root,
[data-neu-theme='light'] {
  --neu-bg: #f2e9e4;
}
[data-neu-theme='dark'] {
  --neu-bg: #22223b;
}
```

## Changing the background of one area

Shadows, text and the accent tint are computed again wherever `--neu-bg` can change: on `:root`,
on any `[data-neu-theme]` element, on `.neu-surface` and on `<neu-surface>`. So a surface with its
own background gets matching shadows and text for everything inside it:

<Demo
  code={`<div class="neu-surface" style="--neu-bg: #f5d0d8">
  <neu-button>Pink</neu-button>
  <neu-switch checked>On pink</neu-switch>
</div>`}
/>

## Shape classes

Plain elements can use the same shadows as the components.

| Class          | Look                                           |
| -------------- | ---------------------------------------------- |
| `.neu-flat`    | No shadow                                      |
| `.neu-raised`  | Raised shadow                                  |
| `.neu-inset`   | Pressed-in shadow                              |
| `.neu-convex`  | Raised, with a gradient from lighter to darker |
| `.neu-concave` | Raised, with the gradient reversed             |

<Demo
  code={`<div class="neu-raised" style="padding: 1rem">raised</div>
<div class="neu-inset" style="padding: 1rem">inset</div>
<div class="neu-convex" style="padding: 1rem">convex</div>
<div class="neu-concave" style="padding: 1rem">concave</div>`}
/>

The shadows are also exported as `--neu-shadow-raised-sm|md|lg` and `--neu-shadow-inset-sm|md|lg`,
for your own `box-shadow` declarations.

## Your CSS always wins

All the token CSS sits in `@layer neu`. Unlayered CSS beats any layered rule whatever its
specificity, so a plain `:root { --neu-accent: ... }` in your stylesheet is enough, with no
`!important` and no selector tricks.

## Before the components are defined

The tokens include a `neu-*:not(:defined)` rule for every tag. It keeps the final size and
`display` and hides the content, so a client-rendered page does not flash or jump while the
definitions load. With [server-side rendering](/neumorphism-ui/guides/ssr/) the shadow roots are
already in the HTML and the placeholder is not needed.
