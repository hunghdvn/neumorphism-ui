## Label

`label` names the spinner for assistive technology and defaults to "Loading". It is also rendered
as visually hidden text, because a live region announces content, not a name. Set a more specific
label when the page has several spinners.

<Demo
  code={`<neu-spinner label="Processing your request"></neu-spinner>
<neu-spinner size="lg" label="Please wait"></neu-spinner>`}
/>
