## Label, help text and error text

`error-text` replaces the browser's validation message once the field is invalid after user
interaction; it does not make the field invalid by itself.

<Demo
  code={`<neu-textarea label="Bio" placeholder="Tell us about yourself" help-text="A few sentences"></neu-textarea>
<neu-textarea label="Notes" required error-text="Notes are required"></neu-textarea>`}
/>

## In a form

A submit shows the form data and Reset restores the defaults.

<Demo
  code={`<form name="demo-form">
  <neu-textarea name="comments" label="Comments" help-text="Enter your comments"></neu-textarea>
  <neu-button type="submit" variant="primary">Submit</neu-button>
  <neu-button type="reset">Reset</neu-button>
  <output></output>
</form>`}
/>
