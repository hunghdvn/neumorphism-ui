## In a form

Submitting shows the form data and Reset restores the defaults.

<Demo
  code={`<form>
  <neu-switch name="notifications" checked>
    Enable notifications
  </neu-switch>
  <neu-button type="submit" variant="primary">Submit</neu-button>
  <neu-button type="reset">Reset</neu-button>
  <output></output>
</form>`}
/>
