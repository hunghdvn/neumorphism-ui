## Horizontal orientation

The default layout places buttons side by side horizontally.

<Demo
  code={`<neu-button-group label="Document actions">
  <neu-button>Save</neu-button>
  <neu-button variant="primary">Save</neu-button>
  <neu-button disabled>Save</neu-button>
</neu-button-group>`}
/>

## Vertical orientation

Use `orientation="vertical"` to stack buttons on top of each other.

<Demo
  code={`<neu-button-group orientation="vertical" label="Document actions">
  <neu-button>Save</neu-button>
  <neu-button variant="primary">Save</neu-button>
  <neu-button disabled>Save</neu-button>
</neu-button-group>`}
/>

## Icon buttons

Icon buttons can also be included inside a button group.

<Demo
  code={`<neu-button-group label="Document actions">
  <neu-icon-button icon="check" label="Confirm"></neu-icon-button>
  <neu-icon-button icon="chevron-down" label="Expand"></neu-icon-button>
  <neu-icon-button icon="x" label="Cancel"></neu-icon-button>
</neu-button-group>`}
/>

## React

<Code
