## Horizontal divider

The default orientation is a horizontal line between blocks of content.

<Demo
  code={`<div style="width: 100%">
  <p>Before</p>
  <neu-divider></neu-divider>
  <p>After</p>
</div>`}
/>

## Vertical divider

Use `orientation="vertical"` for a line between items in a row. Give its parent a height.

<Demo
  code={`<div style="display: flex; align-items: center; gap: 1rem; height: 3rem">
  <span>Before</span>
  <neu-divider orientation="vertical"></neu-divider>
  <span>After</span>
</div>`}
/>
