## Built-in icons

These eight icons ship with the element: `check`, `chevron-down`, `chevron-up`, `plus`, `minus`,
`x`, `alert-circle` and `user`.

## Accessibility

With `label`, the icon is an image named by the label. Without it, the icon is decorative and
hidden from assistive technology.

## Your own icons

Register a library with `registerIconLibrary`, then select it with the `library` attribute.

```js
import { registerIconLibrary } from '@neumorphism-ui/elements/icons.js';

registerIconLibrary('myLib', {
  resolve(name) {
    return `https://example.com/icons/${name}.svg`;
  },
});
```

<Code lang="html" code={`<neu-icon library="myLib" name="check" label="Done"></neu-icon>`} />

React users get the same export from `@neumorphism-ui/react`.

`resolve(name)` may return:

- SVG markup, a string that starts with `<`, which is drawn as is.
- Any other string, or a `URL`, which is fetched and drawn.

Things to know:

- The built-in `system` library cannot be replaced.
- Registering a name again replaces that library and reloads every icon that uses it.
- Icons from a registered library render empty on the server. Only the built-in icons are
  server-rendered.

## Paint containment

The inner box that fills the host has `contain: paint`, so anything painted outside it is cut off. A
`drop-shadow` filter on `::part(svg)` is therefore clipped at that box; leave room inside the
icon, or put the shadow on an element around it.
