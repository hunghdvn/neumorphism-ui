## Variants

`default` is the standard raised button, `primary` marks the main action of a view, and `flat` is
the quietest emphasis.

<Demo
  code={`<neu-button>Default</neu-button>
<neu-button variant="primary">Primary</neu-button>
<neu-button variant="flat">Flat</neu-button>`}
/>

/>

## Disabled

A disabled button ignores clicks and keyboard activation.

<Demo code={`<neu-button disabled>Disabled</neu-button>`} />

## Loading

`loading` shows a spinner and blocks activation while work is in progress.

<Demo code={`<neu-button variant="primary" loading>Saving</neu-button>`} />

## Prefix and suffix

Use the `prefix` and `suffix` slots for content around the label, such as an icon.

<Demo
  code={`<neu-button>
  <span slot="prefix" aria-hidden="true">+</span>
  Add item
</neu-button>
<neu-button variant="primary">
  Next
  <span slot="suffix" aria-hidden="true">→</span>
</neu-button>`}
/>
